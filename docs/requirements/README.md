# 需求设计与验收模板

涉及公开/受信 API、部门同步、数据权限、数据库、租户、事务、并发、权限或跨项目协作的需求，应在编码前创建 `docs/requirements/<feature>.md`。

```markdown
# 需求名称

## 状态
草案 / 开发中 / 待验证 / 已完成

## 背景与目标
## 非目标
## 参与方与前置条件
## 主流程、输入与输出
## 业务规则与状态变化
## 租户、权限与安全边界
## 事务、幂等、并发与重试
## 数据模型、迁移与回滚
## API、事件与兼容性
## 异常场景与可观测性
## 验收条件
- [ ] 可测试或可观察的结果
## 测试矩阵
## 发布顺序与文档更新
```

未确定事项标记为“待决策”，不能由实现者自行变成既定架构。一次只能选择一个明确的活动需求进入开发。
