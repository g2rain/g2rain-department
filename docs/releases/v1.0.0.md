# g2rain-department v1.0.0

## 首次 GHCR 镜像与 API Maven Packages 发布

`g2rain-department` 是 G2rain（谷雨）开源智能体平台中的组织治理与数据权限**控制面**服务。它交付部门树、成员归属、IdP 部门同步、数据权限模型与策略解析、缓存失效广播；它不负责用户与机构主数据、认证或 Token、Gateway 入口校验，也不直接执行下游业务 SQL 的数据隔离。平台整体的可用能力与状态须以 [g2rain 中央仓库](https://github.com/g2rain/g2rain) 为准，不能归因于本组件。

## 构建与运行要求

- Java 25、Maven 3.9+；构建与测试命令：`mvn clean verify`。
- 运行时依赖 MySQL 8.0.13+、Redis、Nacos 与可访问的 `g2rain-basis`；默认 profile 为 `dev`，HTTP 端口为 `8085`。
- 项目版本事实源是根 `pom.xml` 的 `<revision>1.0.0</revision>`，根 parent 为 Spring Boot `4.1.2`；Spring Cloud `2025.1.4`、Jib `3.5.2`，编译 release 为 Java 25。

## 镜像与发布顺序

镜像地址为 `ghcr.io/g2rain/g2rain-department`。成功发布会同时推送 `1.0.0` 与 `sha-<完整提交 SHA>`；从不推送或更新 `latest`。

1. 将发布改动和本文件先合入实际发布分支 `main`。
2. 在已验证的 `main` 提交创建并推送 `v1.0.0` tag。
3. 工作流验证 tag 格式、`origin/main` 可达性、本文件、Maven 版本，执行 `mvn --batch-mode --no-transfer-progress clean install` 后才构建并推送两个标签。

镜像 job 成功后会调用可复用的 Maven 工作流，使用 `mvn -pl g2rain-department-api -am clean deploy` 发布根父 POM 与 `com.g2rain:g2rain-department-api:1.0.0`（含 sources）至 `https://maven.pkg.github.com/g2rain/g2rain-department`；不会发布 Biz 或 Startup。该 Maven 工作流也支持手动运行，但提交必须属于 `main`，并使用并发组避免与自动发布重叠。重复上传同一稳定版本可能冲突，工作流不会删除或覆盖既有制品。Maven 上传失败不回滚已成功推送的镜像。

工作流不创建 GitHub Release、不部署服务。首次成功推送后，维护者需在 GitHub Packages 的 **Package settings → Change visibility → Public** 将 GHCR 包设为公开；如组织管理员禁止该操作，请联系管理员。已有 GHCR 包若被拒绝，还应在 **Package settings → Actions access** 授予目标仓库写权限，并检查组织 Packages 策略。Maven 消费方必须配置仓库和认证；跨仓库 `GITHUB_TOKEN` 读取需要包访问授权，个人读取使用具备 `read:packages` 的 classic PAT，并通过 Maven settings 安全注入，绝不提交 Token。该认证要求不同于公开 GHCR 镜像的匿名拉取。

## 镜像内容、元数据与安全

Jib 从 `eclipse-temurin:25.0.4.1_1-jre` 生成最终镜像，打入 Startup 的 Spring Boot 可执行 Jar（应用 classes、resources 与依赖），主类为 `com.g2rain.department.Application`，容器声明端口 `8085`。镜像使用 Apache-2.0 许可，并带有 OCI `source`、`licenses`、`title`、`version`、`description` 元数据。

Jib 不会像 Dockerfile 那样复制整个工作区；本仓库没有 Dockerfile 或 `.dockerignore`。但 `application-dev.yml` 已被 Startup 资源配置打入 Jar，且与 `codegen.properties` 一样存在已跟踪开发凭据风险（DPT-004）。生产环境必须通过 Secret、环境变量或 Nacos 注入/覆盖凭据，维护者应轮换已暴露的值；本发布准备未删除文件或改写 Git 历史。
